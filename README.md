# CS6102 Exploration in Artificial Intelligence Lab

Python programs and sample outputs for the 13 experiments in the CS6102 Exploration in Artificial Intelligence lab manual.

## Experiments

Each \`ai-experiment-NN\` folder contains a \`main.py\` program and a separate \`output.txt\` sample transcript. Experiments 8 and 9 save chart images in the current directory. Experiment 4 also writes \`students.txt\` and \`students.csv\`; Experiment 12 generates Python templates and notes.

## Setup

Install Python 3 and the libraries used by the data and chart exercises:

\`\`\`sh
python -m pip install -r requirements.txt
\`\`\`

Run an experiment from the repository root, for example:

\`\`\`sh
python ai-experiment-05/main.py
\`\`\`

Replace the experiment number with the folder you want to run. Experiments 1, 3, and 13 accept input; use the sample values shown in their output files.

Experiments 10–13 are local, rule-based demonstrations. They do not call a live Generative AI service.
